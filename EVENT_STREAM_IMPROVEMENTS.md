# UrbanPulse v10 — Event Stream

- Event feed shows current offline nodes, total failure/warning events and accumulated downtime cost.
- New failures distinguish direct overheating from downstream cascading failures.
- Events identify the affected node and can be clicked to inspect it.
- Heat alerts are emitted only on warning-level changes instead of repeatedly every simulation tick.
- Restorations and solar spike actions are logged.
- All/Failures/Warnings tabs show counts.
- All events are simulated and costs/thresholds remain illustrative model assumptions.
